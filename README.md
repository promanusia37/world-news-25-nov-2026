The world's news of Wednesday 25 November 2026 in one image: two tankers hit by mines in the Strait of Hormuz, Houthi strikes on Saudi Arabia, Huawei found guilty in a US court, the Pope's warning after COP31 failed, a roaring US economy, and China's first foreign astronaut — drawn as a one-page newspaper front page (1024×1024) by a deterministic Python program.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (to `/output/entry.png` when `/output` exists, as the bounty sandbox expects). The program needs only Pillow and the DejaVu fonts, draws everything offline, and writes byte-identical output on every run. `summary.txt` lists every story in the image with its sources.
